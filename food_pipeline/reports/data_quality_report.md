### 1.3 能量守恒交叉校验（提示性，不剔除）

- 解释：来源表能量为 Aqua-Calc / Mint Health 实测值，含酒精、有机酸、抗性淀粉等 Atwater 特例；本项目**保留原值**，仅在工作包 C 的输出中标注"来源实测，未做 Atwater 校正"。

### 1.4 生/熟与烹饪口径
字段如"红烧肉""炒莲藕""清蒸鲈鱼"均为**成品菜（熟食）口径**；生食材与熟成品在表内分列（如"鸡蛋"与"炖鸡蛋"）。
**规则：营养计算一律直接使用对应成品菜行，不做生熟换算、不跨口径合并。**（见字段字典 R3）

## 2. 图像数据

### 2.1 food-test.v1i.yolov8
- 图-标一一对应：9472/9472 ✅
- **平均目标数 1.0/图，框普遍近全图 → 无定位信息价值** ❌

### 2.2 DFoodTJ-Rec（10 类试点子集）
| split | 图像数 | 说明 |
|---|---|---|
| train | 9632 | 每类 431–1273 |
| val | 1320 | 每类 60–178 |
| test | 1287 | 每类 55–179 |

- 图像完整性：抽样解码校验 10/10 通过，0 张损坏（v2 解压后全量按 split 分目录）
- **发现并修复的缺陷**：v1 解压脚本未按 split 分目录，train/val/test 同名文件互相覆盖 → 已废弃 v1 输出并用 `extract_subset.py`（v2）重建；受影响目录 `datasets/dfoodtj_subset/` 已重建并复核计数（12239 张 = 9632+1320+1287 ✅）
- 已知问题：部分图像带"大众点评"等水印；类别不均衡（最多/最少 ≈ 3.8×）；图像短边 ~256px

### 2.3 合成检测集 det10（含真值来源声明）
- 规模：train 1600 / val 200 / test 200（8:1:1 ✅ 符合任务书口径）
- 每图目标数分布：1–4 个（权重 0.30/0.38/0.22/0.10）
- **真值框来自粘贴坐标（程序生成），非人工标注**；无框图像不参与（全部合成图均有框）
- 源图 split 隔离：train/val/test 合成图分别仅使用对应 split 源图，**无图像级泄漏**
- 逐图参数（源图路径、偏移、旋转角、边长）记录于 `datasets/det10_synth_manifest.csv`，随机种子 20261023，可完全复现
- 已知域差距：矩形贴块（无 mask 羽化）、程序化背景、无真实光照/遮挡变化 → **指标预期高于真实场景，须以真实图片推理做人工验证**（见 B3）
